# Brownstone 61 — harmonic tremolo plug-in

A model of the brown/blonde-era amp "vibrato" (really a harmonic tremolo):
the guitar is split into lows and highs, and one oscillator pulses them in
opposite directions. That's what makes the swirly, phasey throb instead of a
plain volume wobble. Two more classic circuits are on the MODE knob.

| Control | What it does |
|---|---|
| **SPEED** | Pulse speed, about 0.5–12 Hz. Becomes **RATE** (1/1 … 1/16 notes) when Tempo Sync is on. |
| **INTENSITY** | How deep the pulse goes. |
| **CROSSOVER** | Harmonic mode only: where lows and highs are split (≈250 Hz–3 kHz). Lower = more bass throb, higher = more treble shimmer. |
| **MODE** | **HARMONIC** – brown-era swirl. **BIAS** – tweed-style smooth swell. **OPTO** – blackface-style choppy throb. |
| **OUTPUT** | Final level, −24 to +12 dB. |
| **TEMPO SYNC** | Locks the pulse to your song's tempo and bar lines. |
| **STEREO** WIDE/MONO | Wide: in Harmonic mode the lows and highs trade sides; in Bias/Opto the pulse ping-pongs left/right. |
| **TREMOLO** footswitch | On/off. The amber jewel pulses with the tremolo. |

Classic starting point: Mode HARMONIC, Speed 4, Intensity 7, Crossover 5.
