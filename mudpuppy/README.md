# Mudpuppy — analog BBD slapback delay plug-in

A model of a small 3-knob bucket-brigade delay pedal (20–300 ms), built for
slapback, doubling and short rockabilly echoes.

| Control | What it does |
|---|---|
| **DELAY** | 20–300 ms. The middle of the knob is the slapback zone (80–150 ms). Longer delays get darker, like a real BBD chip. Turning it while repeats ring bends their pitch. |
| **FEEDBACK** | Number of repeats. Past about 8.5 it runs away into self-oscillation (it saturates, it won't blow up). |
| **BLEND** | Echo level against your dry guitar. At 10 the first echo is as loud as the dry. |
| **WOBBLE** | Clock wobble: a little tape-style shimmer in the repeats. |
| **OUTPUT** | Final level, −24 to +12 dB. |
| **TRAILS** | Off = true-bypass style, echoes cut when you switch off. On = echoes ring out. |
| **Footswitch** | On/off, with red LED. |

Starting points: slapback 110 ms / Feedback 0.5 / Blend 6. Rockabilly 140 ms / Feedback 3.5 / Blend 6. Doubling 35 ms / Feedback 1 / Blend 5.
